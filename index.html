Device Finder

See where your own devices are

Each phone or tablet reports its own location to you. Nothing is tracked unless the device is signed in and reporting — so this only works for devices you set up yourself.

No password in this prototype — email just identifies your account. The production version adds an SMS code to the linked phone number to confirm it's really you.

Demo mode. Location is simulated — real browser GPS is blocked inside this preview, so drag the marker or switch on auto-move to see a phone "move". Devices are saved only in this browser (no server yet).
